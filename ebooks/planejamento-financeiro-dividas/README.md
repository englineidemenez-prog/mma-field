# Fora das Dívidas — Guia Prático de Planejamento Financeiro

Ebook em PDF (12 páginas) com dicas práticas para quem quer sair do
endividamento: diagnóstico das dívidas, orçamento, estratégias de
quitação (bola de neve / avalanche), scripts de negociação com
credores, armadilhas comuns, corte de gastos, renda extra, fundo de
emergência e um plano de ação de 30-60-90 dias.

## Arquivos

- `fora-das-dividas.pdf` — o ebook pronto para distribuição.
- `build_ebook.py` — script Python (reportlab) que gera o PDF. Para
  editar o conteúdo ou o design, altere este arquivo e rode:

```bash
pip install reportlab
python3 build_ebook.py
```

O PDF é gerado em `fora-das-dividas.pdf` neste mesmo diretório.
